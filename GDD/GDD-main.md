## 1. ภาพรวมเกม

Grid Dungeon d20 คือ action roguelike แบบ 2D top-down ที่เดินบน grid แบบเรียลไทม์ ใช้ฮีโร่ 4 ตัวจากแคมเปญ D&D จริงของทีม ทุกตัวมีเควสประจำตัวแบบ Elden Ring Nightreign และมีเควสคู่ที่เล่นคนเดียวได้โดยมี AI คุมคู่หู

| หัวข้อ | รายละเอียด |
| --- | --- |
| แนวเกม | Action roguelike, real-time grid, horde survival |
| มุมกล้อง | 2D top-down, pixel sprite (สเปกดูหมวด 5) |
| เอนจิน | Unity 2022 LTS ขึ้นไป (2D, Tilemap) |
| แพลตฟอร์มเป้าหมาย | PC (Windows) |
| ผู้เล่น | 1 คน (เควสคู่ใช้ AI คู่หู), co-op 2 คนเป็นเป้าหมายหลัง MVP |
| ความยาวต่อ run | 20–30 นาที |
| ภาษา | ไทยและอังกฤษ (เขียนไทยก่อน แปลเป็นอังกฤษ) |

### เสาหลักการออกแบบ

1. **ทุกช่องมีความหมาย** เดินทีละช่องแบบเรียลไทม์ ศัตรูเตือนด้วยช่องสีแดงก่อนโจมตีเสมอ ผู้เล่นตายเพราะอ่านเกมพลาด ไม่ใช่เพราะมองไม่เห็น
2. **ฝีมือตัดสินว่าโดนหรือไม่ ลูกเต๋าตัดสินผลลัพธ์** การโจมตีที่เล็งถูกต้องโดนเสมอ d20 ใช้กับดาเมจ คริติคอล skill check และอีเวนต์
3. **ตัวละครคือเรื่องราว** ฮีโร่ทุกตัวมาจากชีตและ lore จริง สกิลในเกมแปลงมาจากความสามารถในชีต และเควสมาจากปมในประวัติ
4. **Build ที่ค้นพบได้** อาวุธรวมร่าง (evolution) ได้แบบ Vampire Survivors ผู้เล่นได้ช่วง "อ๋อ!" จากคอมโบใหม่

### เกมอ้างอิง

| --- | --- |
| Guidus / Guidus Zero | เดินบน grid แบบเรียลไทม์, ช่องเตือนสีแดง, สกิลที่ใช้ได้ทั้งโจมตีและหลบ |
| Vampire Survivors | อาวุธโจมตีอัตโนมัติ, เลือกอัปเกรด 1 ใน 3, weapon evolution |
| Enter the Gungeon | dodge มี i-frame แค่ครึ่งแรก, ห้องทำมือต่อแบบสุ่ม, ฉากที่ใช้เป็นที่กำบังได้ |
| Soul Knight | ด่านละ 5 ห้อง บอสห้องสุดท้าย, ทหารรับจ้าง, รวมอาวุธ |
| Elden Ring Nightreign | Journal และ Remembrance quest แยกตามตัวละคร |
| Dungeons & Dragons 5e | ค่าสถานะ, d20, skill check, spell slot, death save, ไอเทมเวท |

## 2. Core loop การเดินทาง และพื้นที่

เกมคือการเดินทางตามถนนชายฝั่งจากเอเวอร์เมียร์ลงใต้ไปไทด์คราวน์ ตาม canon ที่ปาร์ตี้มุ่งหน้า Waterdeep แต่ละ run ผ่าน 3 จุดแวะที่เลือกบนแผนที่เส้นทางแบบแตกแขนง จุดแวะละ 5 ห้อง ห้องที่ 5 เป็นบอส

1. **กองคาราวาน (ฮับ)** เลือกฮีโร่ เปิด Journal เริ่มเควส อัปเกรดถาวร
2. **เลือกเส้นทาง** แผนที่แสดงทางแยก 2–3 ทาง แต่ละทางบอกพื้นที่และไอคอนห้องเควส (!)
3. **เคลียร์จุดแวะ** 4 ห้อง (ต่อสู้ อีเวนต์ ร้านค้า ห้องพัก ห้องเควส) + บอสพื้นที่
4. **เลเวลอัปภายใน run** เลือก Feat 1 ใน 3
5. **บอสจุดแวะที่ 3** ชนะ = จบช่วงการเดินทาง ได้ Memory Fragment ของฮีโร่ที่ใช้
6. **ตายหรือจบ run** กลับคาราวาน เก็บเงินถาวรและไอเทมเควสที่เก็บได้แล้ว

### กรอบ DM: แต่ละ run คือหนึ่งเซสชัน

เกมทั้งเกมคือ DM กำลังเล่าแคมเปญ แต่ละ run คือเซสชันหนึ่ง เส้นทางและห้องสุ่มใหม่เพราะ DM เล่าไม่เหมือนเดิม พอปาร์ตี้ตาย DM จะพูดทำนอง "เอาใหม่ ฉากนั้นเล่าใหม่ได้" แต่ความทรงจำและความสัมพันธ์ที่ได้มายังอยู่ กรอบนี้อธิบายการเล่นซ้ำแบบ roguelike ได้โดยไม่ต้องมีกลไกพิเศษในโลก

สถานที่ที่อยู่นอกเส้นทาง เช่น เทือกเขากระดูกหิมะ (Spine of the World) บ้านเกิดของ York ปรากฏเป็นห้องความทรงจำเท่านั้น ห้องความทรงจำเกิดในพื้นที่ไหนก็ได้ แต่ถ้าพื้นที่ที่เกี่ยวข้องอยู่ในเส้นทาง จะเกิดที่นั่นก่อน

ในแต่ละองก์ run หนึ่งผ่าน 3 จุดแวะ: พื้นที่คู่ในแถวเดียวกันเลือกได้หนึ่งหรือทั้งสองตามลำดับที่ต้องการ แล้วจบที่พื้นที่บอสขององก์ องก์ III เป็นเส้นทางตายตัวไปสุสาน Ithren

### กองคาราวานเปลวรุ่ง (ฮับ)

ฮับเป็นคาราวานที่เดินทางไปพร้อมปาร์ตี้ จึงเปลี่ยนที่ตั้งตามองก์ ผู้เล่นเห็นเองว่าเดินทางมาไกลแค่ไหน

| องก์ | ที่ตั้งคาราวาน | ระยะทางของ run |
| --- | --- | --- |
| I | นอกประตูเอเวอร์เมียร์ | ป่าเอเวอร์วูด / ถนนชายฝั่ง → บอสที่ประตูเลย์ฮาเวน |
| II | เลย์ฮาเวน | แบล็กมัวร์ / ซากวิหาร → บอสที่ขอบบึงคนจม |
| III | ค่ายขอบบึง | บึงคนจม → สุสาน Ithren (เส้นทางตายตัว) |
| บทส่งท้าย | ไทด์คราวน์ | เนื้อหาหลังจบเกม |

ทุกครั้งที่ York'Runn ช่วยผู้รอดชีวิตจากวิหารได้ คนนั้นจะมาอยู่ในคาราวานและเปิดบริการใหม่ (ช่างตีเหล็ก นักบวช ผู้ฝึก) เป้าหมายข้อ 2 ของ York คือตามหาพวกพ้อง จึงเป็นทั้งเนื้อเรื่องและระบบความก้าวหน้าของฮับ

### การสร้างจุดแวะ

- ห้องทุกห้องออกแบบด้วยมือ (room template) ตามธีมของพื้นที่ แล้วสุ่มต่อกัน ตามแนวทาง Enter the Gungeon
- เควสที่ active ทำให้ห้องเควสถูกใส่ลงในจุดแวะที่ตรงกันก่อนสุ่มห้องอื่น และแผนที่เส้นทางต้องมีทางที่ผ่านจุดนั้นอย่างน้อยหนึ่งทาง
- ห้องต่อสู้มีสิ่งของที่ใช้ประโยชน์ได้ เช่น โต๊ะพลิกเป็นที่กำบัง ถังระเบิด หินที่จับเหวี่ยงได้

## 3. ระบบต่อสู้บน grid

ผู้เล่นคุมการเดิน, dodge และสกิลประจำตัว ส่วนอาวุธเสริมโจมตีอัตโนมัติเป็นรูปแบบช่อง ทุกอย่างเช็กการชนด้วยตำแหน่งช่อง ไม่มี bullet physics

### การควบคุม

| ปุ่ม | การทำงาน |
| --- | --- |
| ลูกศร / WASD | เดิน 1 ช่องต่อการกด กดค้างเดินต่อเนื่อง |
| โจมตีหลัก | โจมตีตามทิศที่หันอยู่ รูปแบบช่องตามฮีโร่ |
| Dodge | พุ่ง 1–2 ช่องตามฮีโร่ (York 1, Atez 2) i-frame เฉพาะครึ่งแรก ครึ่งหลังโดนดาเมจได้ |
| สกิลประจำตัว | ใช้ spell slot หรือคูลดาวน์ |
| Reaction | กดตอนที่กำลังจะโดน เช่น Uncanny Dodge, Stone's Endurance |
| คำสั่งคู่หู | ตามมา / รอตรงนี้ / โจมตีเป้านี้ (เฉพาะเควสคู่) |

### กฎการต่อสู้

- ศัตรูทุกตัว **ต้องเตือนก่อนโจมตี** ด้วยช่องสีแดงหรือเส้นแนวการยิง
- ตีศัตรูจากด้านหลัง (ช่องตรงข้ามกับทิศที่ศัตรูหัน) = Advantage
- จับศัตรูโยนไปชนกำแพง = Stunned 1 จังหวะ
- หนึ่งช่องมีได้ครั้งละหนึ่งตัวละครหรือศัตรู (ยกเว้นบอสที่ใหญ่ 2x2)

## 4. ระบบที่แปลงจาก D&D

หลักสำคัญคือ **ลูกเต๋าไม่ตัดสินว่าโจมตีโดนหรือไม่** ในการต่อสู้เรียลไทม์ เพราะถ้าเล็งแม่นแล้วขึ้น Miss ผู้เล่นจะรู้สึกว่าเกมโกง ลูกเต๋าไปอยู่ที่ผลลัพธ์แทน

| ระบบ D&D | ในเกม |
| --- | --- |
| Ability Scores | STR ดาเมจประชิด · DEX ช่วง i-frame ตอน dodge · CON เลือด · INT ความแรงเวท INT · WIS ระยะเห็นช่องเตือน · CHA ราคาร้านค้าและการคุย |
| d20 + Critical | ทุกการโจมตีทอยแบบมองไม่เห็น ได้ 20 = คริติคอลพร้อมเต๋าเด้งบนจอ |
| Advantage / Disadvantage | ทอย 2 ลูกเอาค่าสูงหรือต่ำ ใช้เป็นบัฟ/ดีบัฟ เช่น ตีจากด้านหลัง |
| Skill Check | อีเวนต์ระหว่างห้อง ทอยเต๋าให้เห็น ใช้ค่า skill จริงจากชีต |
| Spell Slots + Rest | สกิลใหญ่มีจำนวนครั้ง Short Rest ฟื้นบางส่วน Long Rest ฟื้นทั้งหมดแต่ศัตรูแรงขึ้น |
| Reaction | การหลบหรือลดดาเมจที่มีคูลดาวน์ |
| Conditions | Frightened ศัตรูเดินหนี · Prone ล้ม 1 จังหวะ · Stunned หยุด · Poisoned ดาเมจต่อเนื่อง |
| Feats | การ์ดอัปเกรดตอนเลเวลอัป เลือก 1 ใน 3 |
| Magic Item + Attunement | ไอเทม 5 ระดับ (Common → Legendary) ใส่ attune ได้ 3 ชิ้น |
| Cursed Items | แรงมากแต่มีผลเสีย ถอดไม่ได้จนจบ run |
| Death Saving Throws | เลือดหมดทอย d20 สามครั้ง สำเร็จ 3 ครั้ง = ลุกขึ้นพร้อมเลือด 1 หน่วย |
| DM | ผู้บรรยายเปิดและปิดแต่ละเซสชัน พูดแซวตามเหตุการณ์ ร่างในเกมเป็นตัวหัวลูกเต๋า d20 ใส่หมวกทรงสูง |

### DM และตัวละครอื่นในภาพ

- **DM (ยืนยันแล้ว):** ตัวหัวลูกเต๋า d20 ใส่หมวกทรงสูงสีน้ำเงินและสูท (ภาพต่อสู้) ปรากฏตอนเปิดเซสชัน ที่หน้าจอตาย และนั่งหัวโต๊ะในฮับ ตัวเลขบนหน้าเต๋าเปลี่ยนตามผลทอยล่าสุด
- **ศิษย์น้องของ York'Runn (ยืนยันแล้ว):** เด็กผมส้มมีจุดแดงบนหน้าผาก (ภาพกองไฟ) \[เสนอ\] เป็นผู้รอดชีวิตคนแรกจากวิหารที่ York พบ ทำงานเป็นเด็กครัวอยู่ที่เลย์ฮาเวน (จบองก์ I) แล้วเข้าร่วมคาราวาน ในฮับเป็นคนดูแล Relic และช่อง attune เขาเทิดทูน York เหมือนที่ York เคยเทิดทูน Grand Master ทำให้ York ต้องเรียนเป็นคนสอนเสียเอง
- **สิงโตขาว (ยืนยันแล้ว):** ปาร์ตี้ช่วยไว้จากคณะละครสัตว์ที่ถูกโจมตีระหว่างทาง \[เสนอ\] เป็นห้องอีเวนต์บนถนนชายฝั่ง (องก์ I) ปกป้องกรงสัตว์จากโจรให้ครบเวลา หลังจากนั้นสิงโตเดินทางกับคาราวาน นอนข้างกองไฟในฮับ และติด Reya เพราะเป็นสัตว์เวทีเหมือนกัน
- **สัตว์ตัวกลมสีน้ำตาล (ยืนยันแล้ว):** เข้าร่วมก่อนสิงโตขาวเล็กน้อย \[เสนอ\] เป็นมาสคอตของคาราวาน เดินตามสิงโตไปทุกที่ ยังต้องระบุว่าเป็นสัตว์อะไร
- **ยังต้องตั้งชื่อ:** ศิษย์น้อง, สิงโตขาว และสัตว์ตัวกลม

### แนวทางภาพในเกม

- **สไตล์ (ตัดสินแล้ว): pixel sprite** ทั้งเกม ภาพวาดของทีมใช้เป็น concept art และ reference สำหรับทำ sprite
- **ขนาดที่แนะนำ:** 1 ช่อง grid = 32×32 px ฮีโร่และศัตรูทุกตัวยืน 1 ช่อง sprite 32×32 พอดีช่อง (York ตัวใหญ่ให้ดูจากความกว้างและรูปร่างแทนความสูง) บอสใหญ่ 2×2 ช่อง (64×64)
- **ความละเอียด:** อ้างอิง 640×360 ขยาย ×3 เป็น 1920×1080 ด้วย Pixel Perfect Camera เห็นได้ประมาณ 20×11 ช่องต่อจอ

## 6. ระบบเควสประจำตัว (Journal)

ฮีโร่แต่ละตัวมี Journal 8 บท บทที่ 2, 4, 6 มีเควส (Remembrance) บทที่ 8 เป็นบทสุดท้าย ส่วนบทอื่นเป็นเนื้อเรื่องให้อ่าน ปรับมาจากระบบ Remembrance ของ Elden Ring Nightreign

- **ปลดบท** ชนะบอสด้วยฮีโร่ตัวนั้นได้ Memory Fragment 1 ชิ้น = 1 บท
- **ต้องเคลียร์ก่อนไปต่อ** ถ้าบทล่าสุดมีเควส ต้องทำให้เสร็จก่อนบทถัดไปจะเปิด
- **เริ่มเควสจาก Journal ที่ฮับ** มีฉากย้อนความทรงจำสั้นๆ แล้วได้เป้าหมายส่วนตัวสำหรับ run นั้น
- **หยุดหรือสลับเควสได้ทุกเมื่อ** เปลี่ยนฮีโร่แล้วเควสพักไว้
- **เก็บไอเทมเควสแล้วนับทันที** ตายหลังจากนั้นก็ไม่เสียความคืบหน้า
- **ห้องเควส spawn แน่นอน** ไม่ฝากไว้กับการสุ่ม

## 8. เควสคู่: ราคาของการช่วยเหลือ

เควสคู่ของ York'Runn กับ Atez เล่นคนเดียว ผู้เล่นเลือกตัวหนึ่ง อีกตัวเป็น AI **Canon ที่ยืนยันแล้ว:** Grand Master ที่นำอัศวินไปปราบคฤหาสน์ต้องสาปของ Atez (1.3) คือคนเดียวกับอาจารย์ของ York'Runn การส่งกำลังไปที่คฤหาสน์ทำให้วิหารเหลือคนป้องกันน้อยจนถูกบุก (2.7)

- **ปลดล็อก:** ผ่านบท 6 ของทั้ง York'Runn และ Atez
- **ค่าซ่อน Trust 0–100** เริ่มที่ 50 สะสมจากการกระทำ และตัดสินฉากจบ
- **ความรู้ไม่เท่ากัน:** เล่นเป็น Atez ได้ยินความจริงทั้งหมด เล่นเป็น York ได้ยินเฉพาะสิ่งที่ AI Atez เลือกเล่า

### องก์ 1: รอยทางของอาจารย์

- York เจอจดหมายของขุนนางที่ขอความช่วยเหลือจากวิหาร ข้างในมีที่อยู่ของคฤหาสน์
- Atez กลับมาตามหาบันทึกของตระกูลเกี่ยวกับต้นกำเนิดคำสาป
- ทั้งคู่เจอกันที่ประตูคฤหาสน์ ร่วมมือกันเพราะไม่มีทางเลือก Atez ยังไม่บอกว่าที่นี่คือบ้านของเขา
- ชั้นสั้นสอนการเล่นคู่กับ AI (ตามมา / รอตรงนี้ / โจมตีเป้านี้)

### องก์ 2: คฤหาสน์ที่รักกลมเกลียว

- **บทบาทสลับกัน:** คำสาปคือ "ขอให้ทุกคนในคฤหาสน์กลับมารักใคร่กลมเกลียวกับข้าอีกครั้ง" ซากศพครอบครัวจึงไม่โจมตี Atez และพุ่งใส่ York อย่างเดียว Atez เดินผ่านไปกดกลไกได้ ส่วน York ต้องยันคลื่นศัตรู
- ซากศพบางตัวเป็น "แม่" หรือ "พี่ชาย" ของ Atez ทำลายเองหรือปล่อยให้ York จัดการ มีผลต่อบทพูดตอนท้าย
- **ศพอัศวินของวิหาร** กระจายทั่วคฤหาสน์ York หยุดสวดให้ได้ (ยืนนิ่ง 3 วินาทีโดยไม่โดนโจมตี) ครบทุกศพ = Trust +10
- **Speak with Dead** ศพอัศวินพิเศษ 3 ศพเผยความจริงทีละชิ้น
  1. "Grand Master สั่งให้กำลังส่วนใหญ่มาที่นี่"
  2. "วิหารเหลือคนป้องกันน้อยเหลือเกิน"
  3. "เด็กที่หนีไปในคืนนั้น… เป็นต้นเหตุของทั้งหมด"
- เล่นเป็น Atez: ได้ยินทุกประโยค เลือกเล่าทันที เก็บไว้ หรือโกหก / เล่นเป็น York: เห็นแค่ "Atez กำลังสื่อสารกับศพ…" แล้วได้คำตอบที่อาจถูกแต่งเติม

### องก์ 3: แผลที่ถูกผนึก (บอส)

- ผนึกที่ Grand Master ทิ้งไว้เริ่มแตกเมื่อภาชนะแห่งโรคระบาดเข้าใกล้ บอสคือก้อนโรคระบาดที่ตื่นเพราะ Atez

- **เฟส 2:** บอสดูด Atez เข้าหา ถ้า Atez ล้มในเฟสนี้โซนโรคระบาดขยายเร็วสองเท่า

- หลังชนะเจอบันทึกหน้าสุดท้ายของ Grand Master: "ข้าเลือกช่วยคนตรงหน้า โดยรู้ว่าอาจต้องจ่ายด้วยบ้านของเรา" ส่งต่อไปบท 8 ของ York

## 10. AI คู่หู

AI ต้องเก่งพอไม่เป็นภาระ ไม่แย่งความเด่นจากผู้เล่น ไม่ตายเพราะความโง่ และผู้เล่นอ่านออกว่ากำลังจะทำอะไร ระบบ grid ทำให้ AI อ่านช่องเตือนได้จากข้อมูลเดียวกับที่ผู้เล่นเห็น กฎทุกข้อเช็กทุก grid tick บนสุดมีสิทธิ์ก่อน กฎข้อแรกที่เข้าเงื่อนไขจะถูกทำ

**กฎร่วมทุกตัว:** ยืนอยู่ในช่องอันตราย → หาช่องปลอดภัยที่ใกล้ที่สุดด้วย BFS ก่อนทำอย่างอื่น

### AI York'Runn (แทงก์)

1. Atez เลือดต่ำกว่า 30% และมีศัตรูติดตัว → เดินเข้าไปขวาง แล้วใช้ Vow of Enmity กับศัตรูตัวนั้น
2. Atez เลือดต่ำกว่า 25% → Lay on Hands (แหล่งฮีลแสดงบนจอ)
3. ศัตรูติดตัว Atez → จับแล้วโยนออก
4. ไม่เข้าเงื่อนไขข้างบน → ตีศัตรูที่ผู้เล่นตีอยู่
5. **นิสัย:** มีโอกาสเล็กน้อยที่จะพุ่งใส่ศัตรูตัวใหญ่ตามใจตัวเอง (มีคูลดาวน์ และไม่ทำตอนที่ Atez เลือดต่ำ) พร้อมบทพูด "ข้าลืมไปแล้วว่าเราวางแผนอะไรไว้!"

### AI Atez (ยิงไกล)

1. รักษาระยะ 3–4 ช่องหลัง York
2. ยิงเป้าที่ York ใช้ Vow of Enmity ไว้ก่อนตัวอื่น
3. ศัตรูอยู่ใกล้ตั้งแต่ 3 ตัว → Form of Dread
4. องก์ 2 → เดินไปกดกลไกเองเพราะศัตรูไม่ตี
5. ถ้าล้ม → โซนโรคระบาดเริ่มขยาย ผู้เล่นต้องไปชุบภายในเวลาที่กำหนด (ความกดดันหลักเมื่อเล่นเป็น York)

1. ศัตรูอยู่ในระยะ 2 ช่องตั้งแต่ 3 ตัว → Rage แล้วเดินเข้ากลางกลุ่มให้ Storm Aura โดนมากที่สุด
2. คู่หูเลือดต่ำกว่า 40% → Bardic Inspiration ใส่คู่หู
3. ศัตรูเรียงเป็นแนวเดียวกันตั้งแต่ 3 ตัว → Breath Weapon สายฟ้า
4. ไม่เข้าเงื่อนไขข้างบน → ตีศัตรูที่อยู่ใกล้คู่หูที่สุด

### AI Amon (ลอบโจมตี)

1. ศัตรูกำลังหันไปทางคู่หู → เดินอ้อมไปช่องด้านหลังของมัน แล้ว Sneak Attack
2. Amon เลือดต่ำกว่า 30% → Shapechanger แปลงเป็นศัตรูในห้อง ศัตรูเมิน 3 วินาที ใช้หนีออกจากวงล้อม
3. มีศัตรูยิงไกลอยู่นอกระยะประชิด → ขว้าง Psychic Blades
4. ไม่เข้าเงื่อนไขข้างบน → ตามคู่หูห่าง 2 ช่อง รอจังหวะตีหลัง
5. **Reaction:** Uncanny Dodge ทำงานอัตโนมัติเมื่อโดนตี
6. **Passive:** Observant ทำเครื่องหมายของซ่อนและห้องลับบน minimap ให้ผู้เล่น
7. **นิสัย "อยากรู้":** ไม่มีศัตรู → เดินไปดูสิ่งของหรือ NPC ใกล้ๆ แล้วถามคำถามธรรมดา เช่น "ทำไมคนถึงแขวนระฆังไว้หน้าบ้าน"

### ใครเป็นคู่หูกับใครได้

- ฮีโร่ทุกตัวเป็น AI คู่หูได้ ใช้คำสั่ง 3 แบบเดียวกัน กฎที่อ้างถึง "Atez" หรือ "York" ในหัวข้อก่อนหน้าให้อ่านเป็น "คู่หู"
- **เควสคู่:** York × Atez เท่านั้น สลับกันได้ว่าใครเป็นผู้เล่น
- **องก์ III และลาสต์บอส:** ผู้เล่นเลือกฮีโร่ 1 ตัว ถ้าไม่ใช่ Amon คู่หูจะเป็น Amon เสมอ ถ้าเป็น Amon ผู้เล่นเลือกคู่หูได้จากอีกสามตัว
- **นอกเควสคู่และองก์ III:** คู่หูเป็นตัวเลือก เปิดได้หลังจบเควสคู่
- **ไม่ให้แย่งความเด่น:** AI ทำดาเมจ 80% ของตัวเดียวกันตอนผู้เล่นคุม (ปรับได้ตอน playtest)

### AI ในลาสต์บอส

- เฟส 1–2 AI ทุกตัวใช้กฎปกติ แต่จะ**ไม่เดินเข้าประตูแห่งพรเอง** การเลือกนั้นเป็นของผู้เล่น
- เฟส 2 บอสจะก๊อปสกิลของคู่หู AI บ่อยกว่าปกติ เพื่อให้ผู้เล่นเห็นว่ามัน "กลายเป็น" เพื่อน
- เฟส 3 เมื่อเลือดบอสค้างที่ 10% **AI Amon หยุดใช้กฎทั้งหมด** และเดินตรงไปที่แกนกลางทีละช่อง ช้าพอให้ผู้เล่นเห็นและพยายามหยุด
- **พยายามหยุดได้ แต่ไม่สำเร็จ:** York ใช้ Grappler จับได้ แต่ Amon เปลี่ยนร่างหลุดออก · Atez ยิงได้แต่ลำแสงเปิดทางให้ Amon แทน · Reya กดปุ่มสกิลแล้วเธอร้องเพลงแทนการโจมตี
- ถ้าผู้เล่นเป็น Amon: AI คู่หูจะเดินตามมาหยุดอยู่ข้างหลัง 2 ช่อง แล้วพูดบทของตัวเองในฉากสละชีวิต

## 11. แนวทางเทคนิค Unity

ทุกระบบใช้ตำแหน่งช่องบน grid เป็นแหล่งความจริงเดียว ข้อมูลเกมทั้งหมดเก็บเป็น ScriptableObject เพิ่มของได้โดยไม่ต้องแก้โค้ด

| ระบบ | แนวทาง |
| --- | --- |
| Grid | `Tilemap` + `Grid.WorldToCell()` ใช้ทั้งการเดิน การชน และช่องเตือน |
| ช่องเตือน | `DangerMap` ตัวเดียว ศัตรูเขียน ผู้เล่นและ AI อ่าน |
| อาวุธ / ไอเทม / Relic | ScriptableObject (ดาเมจ, คูลดาวน์, รูปแบบช่อง, evolution target) |
| ห้อง | Room template เป็น prefab ตัวสร้างดันเจี้ยนใส่ห้องเควสก่อนสุ่ม |
| เควส | `QuestChapter` ScriptableObject (ฮีโร่, บทที่, ข้อความ Journal, objective, ห้องเควส, ชั้นเป้าหมาย, รางวัล) |
| ศัตรูจำนวนมาก | Object pooling ตั้งแต่วันแรก |
| บทพูด | ไฟล์ข้อความแยกจากโค้ด (เช่น JSON ต่อฉาก) พร้อมทำ localization ทีหลัง |
| เซฟ | JSON ใน `Application.persistentDataPath` (เงิน, บท Journal, Relic, Trust ที่จบแล้ว) |

### AI คู่หู

```csharp
public class CompanionAI : MonoBehaviour {
    public Hero self, partner;
    public DangerMap danger;            // ตัวเดียวกับช่องเตือนของผู้เล่น
    public CompanionRule[] rules;       // เรียงลำดับใน Inspector แต่ละตัวละครใช้ชุดกฎของตัวเอง
    public static int Trust = 50;

    void OnTick() {                     // เรียกทุก grid tick
        if (danger.IsDanger(self.Cell)) { self.MoveTo(danger.NearestSafe(self.Cell)); return; }
        foreach (var r in rules)
            if (r.CanRun(self, partner)) { r.Run(self, partner); return; }
    }
}

public abstract class CompanionRule : ScriptableObject {
    public abstract bool CanRun(Hero self, Hero partner);
    public abstract void Run(Hero self, Hero partner);
}
// กฎ: GuardPartnerRule, LayOnHandsRule, KeepDistanceRule, FocusVowTargetRule
// ponytail: priority list ตายตัว เปลี่ยนเป็น utility score ถ้ากฎตีกันเกิน ~8 ข้อ
```

### เควส

```csharp
[CreateAssetMenu(menuName = "Quest/Chapter")]
public class QuestChapter : ScriptableObject {

```

## 12. ขอบเขต MVP และ roadmap

MVP คือเควสคู่องก์ 2 บอส และฉากจบทั้ง 4 แบบ เพราะรวมระบบหลักครบทุกอย่าง: grid, ฮีโร่ 2 ตัว, AI คู่หู, Trust, Speak with Dead, บทบาทสลับกัน

สเปกละเอียดของ MVP (ศัตรู บอส ห้อง ไอเทม ตัวเลข UI asset และ milestone) อยู่ในแท็บ MVP — คฤหาสน์ Umbra

### ขอบเขต MVP

- [ ] เดินบน grid, dodge, ช่องเตือน, DangerMap
- [ ] ฮีโร่ 2 ตัว: York'Runn และ Atez พร้อมสกิลประจำตัว
- [ ] ศัตรู 3–4 แบบ (ซากศพครอบครัวที่ไม่ตี Atez อยู่ในนั้น)
- [ ] AI คู่หูทั้งสองตัว + คำสั่ง 3 แบบ
- [ ] องก์ 2: คฤหาสน์ ศพอัศวิน Speak with Dead 3 ศพ
- [ ] บอสก้อนโรคระบาด 2 เฟส
- [ ] ระบบ Trust และฉากเผชิญหน้า ฉากจบ A–D
- [ ] อาวุธเสริม 4 ชิ้น + evolution 2 คู่

### Roadmap หลัง MVP

1. องก์ 1 ของเควสคู่
2. เควสประจำตัวบท 2–6 ของ York'Runn และ Atez
3. ฮีโร่ Reya และ Amon พร้อมเควสประจำตัว
4. พื้นที่องก์ I–III พร้อมแผนที่เส้นทาง คาราวานที่ย้ายตามองก์ และความก้าวหน้าถาวร
5. บท 8 ของทุกตัว ฉากพบ Grand Master บอสสุดท้าย และบทส่งท้ายที่ไทด์คราวน์
6. Co-op 2 คน

## 13. บท 8 และตอนจบของเกม

ลาสต์บอสคือ**ร่างจริงของ Amon** เกมชนะได้เพราะ Amon สละชีวิต แต่ไม่ใช่ชัยชนะสมบูรณ์ และในบทส่งท้ายทุกคนเดินตามทางของตัวเอง (สองข้อนี้ยืนยันแล้ว รายละเอียดอื่นเป็นข้อเสนอ)

### ลำดับเหตุการณ์ในองก์ III และบทส่งท้าย

1. **เงื่อนไขเข้าองก์ III:** ผ่านบท 6 ของทั้ง 4 คน และจบเควสคู่แล้ว (ฉากจบไหนก็ได้)
2. **บท 8 ของ York'Runn — พบอาจารย์** ที่ขอบบึงคนจม
3. **บท 7 ของทุกคน — คืนก่อนลงสุสาน** ฉากคุยรอบกองไฟคืนสุดท้าย (ใช้บรรยากาศตามภาพกองไฟของทีม) เป็นบทอ่านอย่างเดียว
4. **บท 8 ของ Amon — หน้าแรก** ลาสต์บอสที่สุสานนักบุญ Ithren
5. **บท 8 ของ Atez — ข้อเสนอสุดท้าย** ที่วงพิธีในบึง (หลังลาสต์บอส)
6. **บท 8 ของ Reya — เวทีใหญ่** ที่ไทด์คราวน์ (บทส่งท้าย)
7. **ฉากปิดเกม — จานที่เกินมาหนึ่งใบ** ทุกคนแยกทางตอนรุ่งอรุณ

### ความจริงของสุสาน Ithren

- **นักบุญ Ithren คือหนึ่งในใบหน้าที่ร่างจริงของ Amon เคยใช้** เมื่อหลายร้อยปีก่อน ผู้คนจำเขาได้ในฐานะนักบุญที่ไม่แก่ลง
- ร่างจริงหลับอยู่ใต้สุสาน แบกความทรงจำมาตั้งแต่ก่อนประวัติศาสตร์ จนแตกตัวเองเป็นเศษเสี้ยว (canon ข้อ 4.3)
- ตอนนี้ร่างจริงกำลังตื่น และ**ดึงเศษเสี้ยวทุกชิ้นกลับมารวม** พร้อมกับดูดความทรงจำของทุกคนที่เข้าใกล้ นี่คือเหตุที่ห้องความทรงจำปรากฏถี่ขึ้นเรื่อยๆ ตลอดการเดินทาง และคนในบึงหายตัว
- ถ้ารวมสำเร็จ เศษเสี้ยวทุกชิ้นจะหายไป รวมถึง Amon ที่เรารู้จัก และร่างจริงจะตื่นขึ้นมาพร้อมความทรงจำของทุกคนที่มันกลืนไป
- ความลับความเป็นอมตะที่ Atez ตามหาคือ Amon เอง และสิ่งที่ Atez ได้เห็นคือราคาของความเป็นอมตะ
- ความฝันของ Amon ถึงทางเดินใต้บึง (canon ข้อ 4.7: ฝันถึงสถานที่ที่ไม่เคยไป) คือเสียงเรียกของร่างจริง
- Beelzebub ไม่ใช่ลาสต์บอสอีกต่อไป แต่ยังเป็นศัตรูของ Atez และกลับมาในบท 8 ของ Atez

### York'Runn — พบอาจารย์

- **Grand Master หายไป 5 ปีเพราะอะไร:** หลังปราบคฤหาสน์ Umbra เขากลับมาเจอวิหารเป็นเถ้า เชื่อว่าทุกคนตายเพราะการตัดสินใจของตัวเอง จึงไม่กลับไปอีก เขาตามรอยโรคระบาดลงใต้มาดูแลคนป่วยที่ขอบบึง ยังทำตามคำสอนของตัวเองคือช่วยคนตรงหน้า
- **เควส:** พาชาวบ้านที่ติดโรค 6 คนผ่านบึงไปที่พัก นับคนที่รอด ไม่นับศัตรูที่ฆ่า เหมือนบท 4
- **ฉากพบ:** Grand Master แก่ลง แขนข้างหนึ่งใช้ไม่ได้จากคืนที่คฤหาสน์ เขาเตือนว่า "สุสานนั้นไม่ใช่ที่ฝังศพ มันคือที่ที่บางสิ่งซึ่งไม่รู้จักความตายนอนอยู่"
- **เควสคู่จ่ายผลที่นี่:** ถ้าได้ฉากจบ B Grand Master จะถามว่า "เด็กจากคฤหาสน์หลังนั้น… เจ้าได้พบเขาหรือเปล่า" แล้ว York ก็รู้ความจริง ถ้าได้ฉากจบ A Atez จะยืนอยู่ด้วยและขอบคุณ Grand Master ต่อหน้า
- **คำถามที่ York ต้องตอบ (2.11):** ท่านรู้ไหมว่าการช่วยครั้งนั้นจะมีราคาเท่าไหร่ Grand Master ตอบว่า "รู้ และถ้าย้อนกลับได้ ข้าก็จะไปอีก แต่ข้าจะไม่ขอให้เจ้าเห็นด้วย" คำตอบนี้ไม่ใช่คำสอน แต่เป็นคนสองคนที่เท่ากันแล้ว
- **ทางเลือก:** "อยู่ช่วยอาจารย์" (หลังจบเกม York กลับมาที่บึง) หรือ "เดินทางต่อ" (หลังจบเกม York ขึ้นเหนือไปตามหาพวกพ้องและผู้บุกรุก)
- **รางวัล:** ชุดพิเศษ + Relic: Vow of Enmity ใช้ปกป้องเพื่อนได้ ศัตรูที่ถูกสาบานจะตีได้แต่ York

### Amon — หน้าแรก (ลาสต์บอส)

**Amon ต้องอยู่ในทีม:** ถ้าผู้เล่นเลือกฮีโร่ตัวอื่น Amon จะมาเป็น AI คู่หู (ใช้ระบบหมวด 10) ส่วนฮีโร่อีกสองตัวปรากฏในฉากคัตซีน

| เฟส | ชื่อ | กลไก |
| --- | --- | --- |
| 1 | พันหน้า | บอสแปลงเป็นคนที่ฮีโร่แต่ละคนอยากพบที่สุด (Grand Master, แม่ของ Atez, ผู้ชมเต็มเวที, เด็กชาวบ้าน) มี "ประตูแห่งพร" เดินเข้าไปจะฟื้นเลือดเต็ม แต่บอสก็ฟื้นและแรงขึ้น |
| 2 | กระจก | บอสก๊อปสกิลของฮีโร่ทั้ง 4 ตัวมาใช้ (Vow of Enmity, Eldritch Blast, Storm Aura, Psychic Blades) ตามความสามารถของ Changeling |
| 3 | ความทรงจำทั้งหมด | ห้องจากทั้งเกมกลายเป็นสนามต่อสู้ทีละห้อง เลือดบอสลดต่ำกว่า 10% ไม่ได้ เพราะฟื้นจากความทรงจำตลอด |

**การจบไฟต์:** เมื่อเลือดบอสค้างที่ 10% ทางเดินไปสู่แกนกลางจะเปิด

- **ถ้าผู้เล่นเป็น Amon:** ต้องเดินเข้าไปเอง (กดค้างทีละช่อง) ไม่มีทางอื่นที่จะชนะ ผู้เล่นจะรู้สึกเองว่าเป็นคนเลือก
- **ถ้าผู้เล่นเป็นตัวอื่น:** AI Amon เดินเข้าไปเอง ผู้เล่นพยายามหยุดได้แต่ไม่สำเร็จ (York จับได้แต่ Amon เปลี่ยนร่างหลุดออก, Atez ยิงเปิดทางให้, Reya ร้องเพลงให้ฟัง)
- **DM วางลูกเต๋าลง:** ครั้งเดียวในเกมที่ DM ไม่ทอย "ฉากนี้… ไม่มีการทอย" เพราะนี่คือการเลือก ไม่ใช่โชค
- **ผล:** Amon นำความทรงจำที่เขาเลือกเก็บเอง (ขนมปังครึ่งก้อน เด็กชาวบ้าน เพื่อนรอบกองไฟ) เข้าไปในร่างจริง ร่างจริงหยุดดึงเศษเสี้ยวและหลับลงอีกครั้ง แต่ไม่ได้ถูกทำลาย หน้ากากขาวของ Amon ตกอยู่บนพื้น

### Atez — ข้อเสนอสุดท้าย

- หลัง Amon ตาย Atez กลับไปที่วงพิธีในบึง Beelzebub ปรากฏอีกครั้ง: "เจ้าเห็นแล้วว่าความตายพรากเพื่อนไปได้ง่ายแค่ไหน ข้าให้เจ้าไม่ต้องตายได้"
- **รับ:** Atez เป็นอมตะ คำสาปถูกกักไว้ตลอดไป แต่ต้องอยู่เฝ้าบึงคนเดียว กลายเป็นสิ่งเดียวกับร่างจริงของ Amon คืออมตะและโดดเดี่ยว (ตอนจบขม)
- **ปฏิเสธ:** สู้กับตัวแทนของ Beelzebub แล้วทำลายวงพิธี คำสาปยังอยู่ในตัว เป้าหมายใหม่คือมีชีวิตและหาทางรักษา ไม่ใช่ความเป็นอมตะ (ตอนจบที่ตรงกับ arc)
- บทพูดสำคัญ (ปฏิเสธ): "ข้าเคยขอพรให้คนรักข้า แล้วพวกเขาก็กลายเป็นซากศพ Amon ไม่เคยขออะไรเลย แต่เขาได้สิ่งนั้นมาเอง"

### Reya — เวทีใหญ่

- เทศกาลที่ไทด์คราวน์ คนจัดงานเห็น Reya ร้องเพลงในคาราวาน แล้วเชิญขึ้นเวทีใหญ่ที่สุดในภูมิภาค
- **รูปแบบ:** 3 เพลง = 3 คลื่น ปกป้องเวทีจากคนเมาและคณะคู่แข่ง (ตีสลบ ไม่ตาย ตามหลัก "ไม่ถึงตาย" ของเธอ) สลับกับ Performance check ระหว่างเพลง
- **ทางเลือกเพลงสุดท้าย:** เพลงฮิตที่เตรียมไว้เพื่อชื่อเสียง หรือเพลงใหม่ "เพลงของคนไร้หน้า" ที่แต่งให้ Amon ทั้งสองทางผ่านเควส แต่เพลงใหม่คือตอนจบที่ตรงกับ arc ผู้ชมร้องตามท่อนสุดท้าย
- **เพื่อนล่องหน:** วางเก้าอี้ว่างตัวหนึ่งไว้บนเวที ไม่มีใครสั่ง Reya เห็นแล้วยิ้ม

### ฉากปิดเกม: จานที่เกินมาหนึ่งใบ

1. **มื้อค่ำสุดท้ายที่ไทด์คราวน์** ปาร์ตี้ตั้งจานเกินมาหนึ่งใบ วางหน้ากากขาวไว้ข้างจาน เหมือนหญิงชราที่ Amon เคยเล่าให้ฟัง (4.5) ทุกคนเพิ่งเข้าใจว่าทำไมนางทำแบบนั้น
2. **รุ่งอรุณ ทุกคนแยกทาง**
   - York: กลับไปช่วย Grand Master ที่บึง หรือขึ้นเหนือไปตามหาพวกพ้อง (ตามทางเลือกบท 8)

## 16. เสียงและเพลง

เพลงใช้แนว medieval fantasy เครื่องอะคูสติก (ลูท ฟลุต กลองมือ) ให้เข้ากับบรรยากาศโต๊ะ D&D ส่วนเสียงประกอบผสมเสียง retro กับเสียงจริง ให้เข้ากับ pixel sprite ทุกแหล่งด้านล่างใช้ฟรี แต่เงื่อนไขสัญญาอนุญาตต่างกัน ต้องตรวจทีละไฟล์
